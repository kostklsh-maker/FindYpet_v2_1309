FindYpet — медальон v2 (светящийся корпус + крышка с QR, кличкой и телефоном)

ФАЙЛЫ
  medallion_v2_body.stl      корпус (одинаковый для всех), уже лежит на боку — как печатать
  plate_bodies_64.3mf        стол A1: 64 корпуса (≈ 19 ч 46 мин, 386 г PLA Glow)
  medallion_v2_lid_101.stl   пример крышки: BELLA, 050-123-4567, QR → findy-pet.com/T/101
  plate_lids_42.3mf          ПРИМЕР стола из 42 крышек (вымышленные клички и телефоны из orders_example.csv)
  medallion_v2.py            генератор: свои крышки из заказов
  orders_example.csv         формат заказов: id,name,phone

ПЕЧАТЬ (Bambu Studio, A1, сопло 0,4 мм закалённое, слой 0,20 мм)
  Корпус: светящийся пластик, без поддержек, плоской стороной на стол (как в файле).
  Крышка: лицом вверх. На высоте 1,6 мм (начало 9-го слоя) — правый клик по ползунку слоёв →
          «Change filament / Сменить пластик». Принтер остановится — вставьте чёрный пластик.
          Слои 1–8 светятся, слои 9–10 (QR, кличка, телефон) — чёрные. AMS не нужен.

СБОРКА
  1) NFC-наклейка Ø20 мм — в круглое гнездо корпуса.
  2) Капля клея по краю гнезда, крышку — на место (зазор 0,15 мм).
  3) Записать ссылку в NFC Tools — можно уже через крышку. Ссылку берите из сообщения бота
     «New order» (строка «✍️ NFC»): у новых жетонов https://findy-pet.com/t/<код>,
     у старых (100, 101, 102) https://findy-pet.com/t/<номер>.
  4) Проверить телефоном: QR и касание открывают страницу питомца.
  5) NFC Tools → «Другое» → «Заблокировать метку» (необратимо): тогда чужой телефон
     не перезапишет ссылку. Ссылка постоянная, менять её не придётся.
  Ремень ошейника (до 25 мм) — через прорези в ушках.

СВОИ КРЫШКИ
  С 16.10.2026 новый жетон получает вместо номера случайный код из 7 знаков (например K7QM2XA):
  по номеру его страницу открыть нельзя. Готовую команду с кодом присылает бот в сообщении «New order».
  python3 medallion_v2.py lid K7QM2XA ROCKY 054-222-3344    → одна крышка (новый жетон, по коду)
  python3 medallion_v2.py lid 101 BELLA 050-123-4567        → одна крышка (старый жетон, по номеру)
  python3 medallion_v2.py plate orders.csv                  → стол до 42 крышек
  Нужны Python 3, numpy, opencv-python, Pillow (корпус — ещё scikit-image).
  QR кодирует заглавными (так QR меньше и надёжнее): у новых жетонов HTTPS://FINDY-PET.COM/<код>,
  у старых HTTPS://FINDY-PET.COM/T/<номер>. Сайт перенаправляет оба адреса на страницу питомца.
  Если QR не помещается на крышку, скрипт остановится и напишет об этом — крышка не создаётся.
